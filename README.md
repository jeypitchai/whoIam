# Jeyakrishnan Pitchaikani — personal portfolio

A responsive, dependency-free personal website prepared for https://jeypitchai.github.io/whoIam/.

## Publish on GitHub Pages

1. Create a public repository named `whoIam` under `jeypitchai`.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. In Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.
4. Wait for the Pages deployment to finish. The website will be served at the address above.

If a repository named `whoIam` already exists, inspect its contents before adding this website.

## Content

Built from publicly indexed LinkedIn information and career details shared by the owner. Customer names are omitted from project descriptions. No personal photograph or email address was supplied. Review project descriptions and public disclosure suitability before publishing.

## Edit

All content and styling live in `index.html`. No build step is required. Links and assets use paths compatible with project Pages hosting.
