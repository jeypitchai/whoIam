# Customer artwork

These twelve PNG logos were supplied by the portfolio owner on October 8, 2026 and are copied unchanged. Customer names and relationships are supplied by the owner.

`src/data/customers.ts` records each image's dimensions, display width, and crop bounds. `CustomerExperience` frames the original artwork with CSS to remove excessive blank padding. Asurion's monochrome white-on-black source uses CSS inversion for the white card background. Brand colors in the other artwork are retained.

The Work page shows every customer in a responsive grid with a finite, once-per-visit entrance animation and reduced-motion support. Logos are not links or endorsements.
